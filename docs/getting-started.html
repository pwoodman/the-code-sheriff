The Code Sheriff

Polyglot quality gates. One command in the repo. Heavy work stays on your machine. GitHub uses that repo’s Actions minutes.

The whole setup

Run this in the repository

uvx --from git+https://github.com/pwoodman/the-code-sheriff.git \ quality setup

No uv? pip install "git+https://github.com/pwoodman/the-code-sheriff.git" then quality setup

That command does
1. Writes default quality.toml, a pinned GitHub workflow, and git hooks
2. Requires the status check named The Code Sheriff if gh is logged in
3. Runs the first gates and writes .quality-baseline.json (adopt policy)
Then commit those files. Pull requests are covered.
On your device
Commit and push

Format, lint, DRY, security, compile, coverage, audit, and UI tests. The slow gates never leave your machine unless you opt in.

On GitHub
Pull requests

PR gates: format, lint, security, impact, audit, version, review. Runs on that repo’s minutes. No hosted worker. No telemetry.

Optional

You do not need a GitHub App. Add one only if comments should come from the App bot:

quality github-app register
policy = adopt ci.mode = local webhook off you pay your minutes
