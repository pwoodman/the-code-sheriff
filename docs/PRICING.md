# Pricing

The Code Sheriff is MIT licensed. There is no paid SKU in this repository.

- Public and private repositories can run the CLI and GitHub Actions workflow
  on **their own** minutes.
- BYOK (Anthropic, OpenAI, Azure, Bedrock, Gemini, OpenRouter, Ollama, or an
  OpenAI-compatible proxy) is billed by that provider. Sheriff records usage
  in `.quality-reports/cost.json` and honors optional caps.
- A later hosted control plane is optional and not required for the 100-item
  reviewer checklist.
